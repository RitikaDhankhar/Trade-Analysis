# Trade-Analysis
Trader behavior vs market sentiment analysis
## Overview
This project analyzes the relationship between trader behavior and market sentiment using trading data. The goal is to identify patterns in profitability, trading activity, and risk behavior.

## Methodology
1. Data cleaning and preprocessing
2. Exploratory Data Analysis
3. Visualization of trader behavior patterns
4. Strategy recommendations based on insights
5. Bonus: Predictive model and trader clustering

## Key Insights
- Trader profitability varies across different market sentiment conditions.
- Aggressive traders take larger positions and higher risk.
- Frequent traders execute more trades compared to infrequent traders.

## Strategy Recommendations
- Adaptive trading strategies based on market sentiment.
- Risk-based trader segmentation for better decision-making.

## Bonus Features
- Logistic Regression model to predict trade profitability
- K-Means clustering to identify trader archetypes
- Streamlit dashboard for interactive visualization
